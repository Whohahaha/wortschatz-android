# 德语单词（Wortschatz）安卓原型

这是一个原生安卓 App，用 Kotlin 和 Jetpack Compose 写成，目标系统是 Android 16（API 36），最低支持 Android 8.0。目前完成的是调研报告路线图里的第一阶段：一个自己能用的最小版本。

## 怎么跑起来

1. 安装最新版 Android Studio。
2. 用 **File → Open** 打开 `wortschatz-android` 文件夹，等 Gradle 同步完成。如果 Android Studio 提示升级 AGP 或 Gradle，可以直接接受。
3. 连上手机（需要打开 USB 调试）或启动一台 Android 16 模拟器，然后点 ▶ Run。

发音用的是系统自带的 TTS 引擎。如果手机上没有德语语音，到系统设置的“文字转语音”里下载德语语音包即可。

## 第一阶段做了什么

- **一个词拆成几张卡，分别安排复习**：释义卡、冠词卡（der/die/das 三选一，由 App 判对错）、复数卡、动词三形卡。冠词、复数和变位卡要等这个词的释义卡毕业以后才会解锁，而且同一个词一天只出一张卡，免得几张卡互相提示答案。
- **FSRS-5 调度**：复习间隔按 90% 的目标记忆保持率来算。学习步长是 1 分钟和 10 分钟，记错的词 10 分钟后重新学。按钮上会显示每个选项对应的下次复习时间。
- **复习顺序**：先出正在学习中的卡，再出今天到期的复习（最容易忘的排在最前），然后才是新词。
- **手势**：5 套预设（单手速刷、卡片滑动、点击分区、国产 App 式、音量键）加一个自定义模式，11 种手势（三个点击区、双击、长按、四个方向滑动、两个音量键）都可以单独设置。底部有“不认识 / 模糊 / 认识”三个按钮兜底，随时可以撤销上一题。
- **冠词配色**：der 蓝、die 红、das 绿，全 App 统一。可分动词的前缀会标出来（an·rufen）。
- **发音**：每个词（名词连同冠词）、复数、动词三形和例句都预先用 Piper 离线神经网络 TTS 生成（德语 Thorsten 音色，CC0 授权），打包进 APK，不依赖手机自带的语音引擎。找不到内置音频时才用系统 TTS；手机也没有德语语音时会提示一次。冠词卡在你作答之前不会发音，免得直接听出答案。音频在 GitHub 编译时由 `tools/gen_audio.py` 生成并缓存。
- **首页**：显示今天的新词、学习中和待复习数量，未来 7 天的复习预测，可以调整每天新词数。
- **内置词书**：完整的歌德 A1 词书（776 个词条），词头依据歌德学院 Goethe-Zertifikat A1（Start Deutsch 1）公开词表，另加数字、星期、月份、颜色等词组和 6 个早期示例词。中文释义和例句都是本项目自己写的，复数和动词变位来自 Wiktionary 数据。源文件在 `tools/goethe_a1/source_*.tsv`，用 `tools/goethe_a1/build.py` 生成 `app/src/main/assets/wordbooks/goethe_a1.tsv`。

## 0.3.0 新增

- **滑动手感**：滑动距离缩短到 64dp（可在手势设置里调成灵敏 44dp 或稳重 110dp），轻快一甩也能触发；方向在起手时就锁定，没设动作的方向会有阻力；跨过阈值时有轻微震动。
- **词书管理和导入**：首页右上角“词书”可以切换和删除词书，也可以导入 Anki 卡组（.apkg，新旧格式都支持）、CSV / 制表符文本（UTF-8 或 GBK）、Quizlet 导出和本 App 自己的词书格式，还能从别的 App 直接分享文件或一段单词表过来。导入时会自动识别各列是什么，可以手动改；能读懂 `der Tisch, -e`、`Tisch, der`、`r Tisch`、`der Stuhl, ¨-e`、`an|rufen`、`fahren (fährt, fuhr, ist gefahren)` 等常见写法。词表缺的冠词、复数和动词变位会用补全词典自动补上（数据来自 Wiktionary，经 kaikki.org 整理，CC BY-SA 4.0，由 `tools/lexicon/build_lexicon.py` 在编译时生成）。
- **离线发音**：导入的词书没有内置录音，App 会在后台（每天一次、导入或切换词书后立即一次）用手机自带的德语语音，把今天和明天要学的词的发音提前生成到本地，学习时不需要联网。发音来源依次是：内置录音，然后是提前生成的文件，最后才是现场合成。

## 0.4.0 新增

- 内置词书换成完整的歌德 A1 词书。
- 每天新词默认 25 个，改成 5 个一档的滑块，右边实时显示按这个速度大约多少天能学完当前词书。
- 卡片上任何位置都能滑动，包括例句上方；点例句仍然会朗读例句。

## 0.5.0 新增（借鉴同行）

- **斩**：学习页右上角“斩”，或在手势设置里把某个手势设为“斩”，已经会的词从此不再出现，可以撤销。“国产 App 式”手势方案的上滑就是斩。
- **冠词快练**：首页进入，20 个名词一轮，屏幕下方三分 der / die / das，连对计数，结束后列出错题。只是练习，不影响复习计划。
- **冠词规律提示**：名词答完后提示词尾规律（-ung → die、-chen → das 等），不符合规律的例外词会标出来。
- **可分动词高亮**：例句里拆开的动词两部分（rufe … an）加粗高亮。
- **连续天数和积压说明**：首页显示连续学习天数；复习积压超过每日上限时，说明会分几天消化。
- **每日提醒**：首页打开，选择时间；只在有词要学时提醒，并写明数量。

## 0.6.0 新增

- 首页精简：只留今日数字、开始学习、连续天数和冠词快练入口，其余移到新的「设置」页。
- 设置页：每日新词、新词顺序、未来 7 天复习量、词书、提醒、手势。
- 新词顺序可选：随机（每次切到随机重新洗牌，之后保持不变）、从 A 开始（德语字母序，ä 归 a）、词书顺序。

## 0.7.0 新增（借鉴 Memorion）

- 拼写卡：看中文打出德语，带 ä ö ü ß 快捷键；大小写、ae/oe/ue/ss 写法或错一个字母算“模糊”。
- 填空卡：例句挖掉目标词（可分动词挖两处），按句中形式填写；A1 词书 776 词里 747 个有填空卡。
- 两种新卡都在释义卡毕业后解锁，同一个词一天只出一张；可在设置里分别关掉。
- 听数字：随机读一个德语数字，用数字键盘输入；0–20、21–99、100–999、1000–9999、年份五档。0–100 打包了离线发音。
- 点例句查词：点例句里的任意词，离线显示原形、冠词、复数、动词三形，在词书里的还显示中文释义。

## 0.8.0：更新不再丢进度

- 0.7.0 及以前每次 CI 构建都用临时生成的调试密钥签名，签名每版不同，手机只能卸载重装，进度随之丢失。
- 现在所有构建都用 `signing/wortschatz.jks` 这把固定密钥签名，CI 会核对证书指纹（见 `signing/keystore.properties`），对不上就不发布。**这把密钥不能丢、不能换。**
- 每天自动备份进度、设置和导入的词书到「下载/Wortschatz/wortschatz-backup.zip」，卸载也不会删。设置页可立即备份、导出、恢复；新装后没有进度时首页提示从备份恢复。
- 数据规则：数据库只通过 `onUpgrade` 加表加列，不删不重建；设置项改名时保留旧键的读取；新卡片类型由程序自动补建。这样旧版本的数据和备份都能在新版本里打开。
- 首页的词书、设置、冠词快练、听数字入口都改成按钮。

## 0.9.0 新增（Memorion 第二轮）

- 词表：搜索德语或中文，按全部 / 难词 / 学习中 / 已掌握 / 未学 / 已斩筛选；斩掉的词可以恢复。
- 难词：同一张卡忘了 4 次以上的词单独列出，按遗忘次数排序，并注明是哪种卡忘得多。
- 统计：近 30 天答对率、17 周学习日历、最长连续天数、掌握程度分布、里程碑。
- 慢速朗读（0.75 倍）开关。
- 跟读：释义卡答案页点「🎙 跟读」录音，再点一次停止，先放自己的录音再放标准发音。
- 易混词：答案页列出词书里中文意思相同的其他词。

## 0.9.1 修正

- 长词（如 die Sehenswürdigkeit）不再折行、不再和冠词叠在一起：单词始终一行，放不下就自动缩小字号。
- 滑动改成连续的二维拖动：卡片跟手斜着走，上下和左右之间来回转向不会中断；松手时按位移较大的方向算。方向提示在接近对角线时淡出，不会跳变。
- 拖动时答案（释义、复数、动词三形）随拖动距离逐渐显现，到触发距离时完全显示；松手弹回则重新隐藏。

## 0.10.0 新增：下载词书

- 「词书」页新增「下载词书」：歌德 A2 词书（A2 词表比 A1 新增的 588 个词）和歌德 B1 词书（B1 词表比 A1、A2 新增的 1640 个词），都带离线发音，中文释义和例句为本项目自编。
- 词书放在公开仓库 [whohahaha/wortschatz-books](https://github.com/whohahaha/wortschatz-books)，App 先从 GitHub 下载，连不上时改用 jsDelivr 镜像；每个文件都按 SHA-256 校验，下载完整才安装。
- 进度跟着词条走，不跟着词书文件走：切换词书、删除下载的词书再重新下载、更新词书，背过的词都接着之前的进度。每本词书显示已学多少词、有多少张待复习。
- 词书库里有新版本时，词书旁边出现「更新」，更新后进度不变。

## 0.11.0 新增

- 首页按功能分层：开始学习是唯一的实心主按钮；词书、词表、统计是顶部的线框按钮；冠词快练、听数字放在底部“加练”区，用浅色按钮并写明练什么。
- 多题型验证：新词第一次是回想释义；同一轮里再出现时改成四选一（德选中、中选德交替），干扰项同词性、拼写相近、意思不重叠；记忆不满一周的复习也用四选一，之后回到自由回想。四选一由 App 判对错。
- 每张卡顶部有彩色题型标签（回想释义 / 四选一 / 拼写 / 填空 / 选冠词 …）。
- 释义毕业后的卡按“冠词 → 拼写 → 复数 → 填空 → 动词三形”的顺序每天解锁一张，拼写卡比以前早出现。
- 动词显示现在时六个人称的变位（不规则动词和情态动词查表）。
- 推到 `release/**` 分支会编译并发布一个 `build-release-…` 预发布，用于在合并前出包。

## 0.12.0 新增

- 设置页底部“重置学习进度…”：可以只重置当前词书，或重置全部词书。会清空复习记录、记忆进度和“斩”掉的词；词书、发音和设置不变。重置前另存一份 `wortschatz-重置前-日期.zip` 到“下载/Wortschatz”，不会被每天的自动备份覆盖，可以从“从备份恢复”找回。
- 中途退出不丢作答：每次作答都立刻写进数据库。以前四选一、选冠词和拼写/填空是在显示对错的那一两秒之后才记，这时退出会丢掉这一题；现在判完立刻记，停顿只用来看答案。

## 代码结构

```
core/   纯 Kotlin，不依赖安卓，可以在任何 JVM 上跑单元测试
  Gestures.kt          手势、动作、预设方案
  fsrs/Fsrs.kt         FSRS-5 调度算法
  Model.kt             词条、卡片类型、复习记录
  WordBook.kt          词书（TSV）解析
  Catalog.kt           可下载词书列表（词书仓库的 index.json）
  BookProgress.kt      每本词书的学习进度
  StudySession.kt      选下一张卡、记录作答、撤销、统计
  imports/             导入：表格解析、德语词头写法识别、列识别和补全、Anki 卡组读取
app/    安卓应用
  data/SqliteStudyStore.kt   SQLite 存储：card 表保存当前状态，review_log 只追加，以后做同步时交换的就是这张表
  data/BookRepository.kt     内置、下载和导入的词书（保存在 files/books/，用本 App 的格式；下载词书的发音在 files/book-audio/）
  data/BookDownloader.kt     从词书仓库下载词书和发音
  AudioPrepJob.kt            后台提前生成发音
  StudyViewModel.kt          界面状态
  ui/                        Compose 界面
```

运行核心逻辑的测试：`./gradlew :core:test`

## 已验证和未验证的部分

- `core` 模块的 32 个单元测试已经全部通过，覆盖调度算法、拆卡、解锁、撤销、数据重新加载，示例词书的解析，手势预设，发音文件的命名，以及导入（用真实生成的新旧两种 Anki 卡组测试）。
- 界面代码用 Compose Desktop 1.8 做过编译检查，SQLite 存储和发音代码用 Android 16 的 API 做过编译检查。
- 每次推送到 main 分支，GitHub Actions 都会自动跑测试并编译 APK，最新的调试版 APK 发布在仓库的 Releases 页面（标签 `latest`）。
- 还没有在真机上跑过，使用中遇到问题直接告诉我。
